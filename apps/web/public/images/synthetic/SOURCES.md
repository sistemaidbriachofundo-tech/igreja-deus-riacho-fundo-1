# Imagens sintéticas da homologação

Estes arquivos são desenhos vetoriais gerados por `scripts/hml/presentation/render-avatars.mjs`.

- Não são fotografias.
- Não retratam pessoas reais.
- Não vêm do Unsplash nem de outro banco de imagens.
- Não substituem as fotos oficiais da congregação usadas na landing.

Cada avatar usa as cores da identidade (creme, marrom, dourado, bronze, terracota), uma forma geométrica e as iniciais do nome fictício. As cenas são fachadas abstratas, sem silhueta humana.

O script de massa grava em `photoStorageKey` a chave `synthetic/avatars/<slug>.svg`. Os bytes estão nesta pasta. O storage privado da API não é preenchido daqui.
